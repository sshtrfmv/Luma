# Проверка публикационного дерева 0.9.0

- Проверены исходники, Gradle, shell/Python-утилиты и ресурсы: реальных токенов TMDB/VPN, паролей и ключей подписи в этом дереве не обнаружено. Добавлена воспроизводимая ограниченная проверка tools/check-publication.py; это не гарантия отсутствия всех возможных секретов.
- Удалён предустановленный адрес локального ТВ. Тестовые адреса используют документационный диапазон. Персональные логи, скриншоты, копии настроек и SDK-пути не включены.
- Отсутствуют старые растровые референсы и вшитые кинокадры. Установщик копирует только перечисленные файлы, удаление устаревших ресурсов обратимо через backup/restore.
- Код лицензирован MIT с исключениями для Gradle Wrapper, TMDB-атрибуции и чужих марок. Их уведомления сохранены отдельно.
- Сборка закреплена на JDK17, Gradle8.9, AGP8.7.3, API35/target33/min26. applicationId прежний.
- Новое дерево не включает старый Kotlin-код dev.tvlauncher или его ключ подписи. Существующий закрытый репозиторий имеет отдельную старую историю; до её раскрытия нужен отдельный разбор. Публикационная ветка и PR не меняют его видимость.

Локальные проверки: компиляция Java /328 проверок, Python-тесты, XML, публикационный фильтр, установка и точный откат. Полную Android APK-сборку и lint проверяет GitHub Actions; актуальный результат связан с PR подготовки0.9.0. SDK локально недоступен. CI обнаружил и позволил исправить границу API getOwnerUid: вызов теперь защищён проверкой Android API30, а не29. Отрисовка0.9.0 на реальном ТВ в этой среде не проверяется.

## Изменения 0.10.0

Локально: 348 Java-проверок и 30 Python-тестов. Добавлены проверки поиска города, различения одноимённых городов, URL-кодирования, координат, сохранения выбора и сброса старого прогноза. Установка исходников и точный откат проверены на временной копии проекта с сохранением local.properties. Android APK/lint для 0.10.0 и UI на реальном ТВ ещё не проверены: загрузка новых изменений в GitHub остановлена автоматической проверкой разрешения.

## Проверка 0.11.0

Компиляция всех Java-исходников и 348 Java-проверок пройдены. Установка поверх временной копии 0.10.0 и точный откат с сохранением local.properties проверены. Android APK/lint и отрисовка 0.11.0 на реальном ТВ в этой среде не проверялись. GitHub не обновляется по указанию пользователя.

## Проверка 0.12.0

Все Java-исходники скомпилированы, 348 проверок пройдены. Проверены установка поверх временной копии 0.11.0 и точный откат. Переходы фокуса просмотрены в исходниках: общая схема строк HDMI, выход из бокового меню, стрелки баннера и возврат после восстановления. Это не тест пульта или отрисовки на ТВ. Полная APK-сборка/lint локально недоступны; GitHub по указанию пользователя не обновляется.

## Итоговая версия 1.0.0

Основана на подтверждённой пользователем 0.12.0, функциональный код не менялся. Подготовлены инструкции сборки с прежним локальным ключом и обновлена схема главной без удалённых плиток. Публикация остаётся закрытой; ключи не переносятся. Актуальные реальные скриншоты не получены и не подменяются иллюстрацией. Результат Android CI проверяется по финальному commit SHA.

## Чистое открытое дерево

Файлы перенесены по списку git ls-files без .git старого проекта. Пять приложенных пользователем скриншотов просмотрены и подготовлены с точными хешами допустимых растров; их открытая публикация ожидает отдельного согласия владельца. Токенов, ключей и личных сетевых адресов на снимках не обнаружено. Это подготовка нового репозитория, а не открытие прежней истории.
