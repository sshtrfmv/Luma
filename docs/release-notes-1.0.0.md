# Luma 1.0.0

Первый открытый выпуск Luma — нативного лаунчера для Android TV с управлением пультом.

## Возможности

- Главный экран с баннером, быстрым запуском приложений, подборками и погодой.
- Каталог фильмов и сериалов TMDB: поиск, фильтры, сортировка, страницы и избранное.
- Открытие выбранной карточки в установленной Lampa.
- Раздел HDMI-устройств с названиями и значками; доступные функции зависят от прошивки.
- Управление AmneziaWG при разрешённом внешнем управлении.
- Экспорт и восстановление настроек без токена TMDB и ключей VPN.

## Совместимость

Android 8.0 и новее. Работа версии 0.12.0, на которой основана 1.0.0, подтверждена пользователем на SaluteTV с Android 13. В 1.0.0 изменены версия и документация; совместимость с другими прошивками требует проверки.

## Установка и обновление

Установи подписанный APK из вложений к релизу. Для обновления требуется та же подпись, что у установленной версии; при несовпадении подписи не удаляй приложение — используй сборку с прежним ключом.

Lampa, Zona и VPN-клиенты устанавливаются отдельно. Для каталога укажи свой TMDB API Read Access Token в настройках. Доступность TMDB зависит от сети и региона.

## Ограничения

Продолжение просмотра, раздельная маршрутизация VPN, загрузочная заставка и автообновление APK не реализованы. HDMI зависит от прошивки и не гарантирует определение активного видеосигнала.
