# Luma 1.0.0

Итоговая версия основана на 0.12.0, подтверждённой пользователем на SaluteTV Android 13. Изменены версия и документация; applicationId сохранён, versionCode 21. Совместимость с другими телевизорами не подтверждена.

## Обновить существующий проект на Mac

Скачай Luma-1.0.0.zip в Downloads и выполни:

```bash
unzip -o "$HOME/Downloads/Luma-1.0.0.zip" -d "$HOME/Downloads/"
bash "$HOME/Downloads/Luma-1.0.0/install.sh"
```

Открой прежний проект TVLauncher 2 в Android Studio, оставь Gradle JVM = JDK 17 и нажми Run. Сохрани локальный debug.keystore: он необходим для обновления установленной версии без удаления данных. Команда отката исходников выводится install.sh.

## Получить APK с прежней подписью

В Terminal:

```bash
cd "$HOME/Downloads/TVLauncher 2"
bash ./gradlew --no-daemon :app:assembleDebug :app:lintDebug jvmRegression
```

Файл: app/build/outputs/apk/debug/app-debug.apk. Для отдельного сохранения:

```bash
cp app/build/outputs/apk/debug/app-debug.apk "$HOME/Desktop/Luma-1.0.0.apk"
```

Устанавливать поверх существующего приложения можно только APK с той же подписью. Не удаляй приложение при ошибке несовпадения подписи; используй прежний ключ на Mac. CI APK имеет тестовую подпись runner и для такого обновления не предназначен.

## Скриншоты

Открой нужный экран на ТВ. При единственном подключённом ADB-устройстве:

```bash
adb exec-out screencap -p > "$HOME/Desktop/luma-home.png"
```

Аналогично сохрани экраны приложений, каталога, настроек и устройств с разными именами. Реальные снимки подготовлены, но их открытая публикация ожидает отдельного подтверждения владельца. README пока содержит собственную схему компоновки.

## Что не входит

Lampa, Zona и VPN-клиенты устанавливаются отдельно. Токен TMDB задаётся пользователем; доступность сервиса зависит от сети. Продолжение просмотра, раздельный VPN, заставка загрузки и автообновление APK отложены. HDMI зависит от данных прошивки; последний выбор не доказывает активный видеосигнал. Город погоды не включён в существующий формат экспорта настроек.
