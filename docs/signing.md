# Подпись APK и сохранение данных

Luma не поставляет ключи подписи. Android Studio использует локальный debug.keystore; его необходимо сохранить на своём компьютере, чтобы обновлять прежние debug-сборки с тем же applicationId. Не коммить его и не отправляй в чат.

GitHub Actions создаёт debug APK на runner: его подпись не гарантирует совместимость с установленной локальной сборкой. Не делай `adb uninstall` при INSTALL_FAILED_UPDATE_INCOMPATIBLE — данные будут потеряны. Собери на прежнем Mac с прежним ключом либо сначала продумай перенос данных.

Для собственного стабильного релиза создай отдельный release-ключ вне репозитория и храни его вместе с паролями в защищённом хранилище. Публичная сборка здесь не настроена на release-подпись. `assembleRelease` без signingConfig не создаёт подписанный распространяемый релиз; не называй такой APK готовым релизом.

Текущий пакет: `ru.sasha.tvlauncher`. Старый Kotlin-эксперимент `dev.tvlauncher` — другое приложение. Здесь нет миграции его приватных данных или ключа.

Ключ, однажды попавший в Git, остаётся в старых коммитах даже после удаления файла из новой ветки. Не делай такой репозиторий публичным без отдельного решения по истории и ключу. Открытая версия Luma создаётся в новом репозитории без старых коммитов. Прежний приватный проект остаётся закрытым.
